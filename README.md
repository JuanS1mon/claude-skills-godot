# claude-skills-godot

Skills de Claude para hacer juegos en Godot 4.

- `godot-2d-en-3d`: estética 2D dentro de un mundo 3D (2.5D / HD-2D), personaje de plataformas, toon shader, pruebas con input simulado.
- `godot-juego-movil`: juegos 2D móviles en GDScript (escenas, UI táctil, economía, exportar a Android).

## Instalar en Claude Code

Copiar las carpetas de los skills dentro de `~/.claude/skills/` (en Windows: `C:\Users\<usuario>\.claude\skills\`).
Se invocan con `/godot-2d-en-3d` o `/godot-juego-movil`, y Claude los usa solo cuando el trabajo encaja.
